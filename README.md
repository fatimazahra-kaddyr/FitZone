# FitZone Gym Website

## About the Project

FitZone is a simple and modern gym website created as a web development project.

The website allows users to discover gym services, view membership plans, learn about trainers and register for a membership.

## Features

* Home page
* Gym services
* Membership plans
* Trainers section
* Registration form
* Interactive buttons
* Responsive design

## Technologies

* HTML
* CSS
* JavaScript

## Project Structure

```text
FitZone/
├── index.html
├── style.css
└── script.js
```

## Purpose

This project was created to practice frontend web development and improve my skills in HTML, CSS and JavaScript.
